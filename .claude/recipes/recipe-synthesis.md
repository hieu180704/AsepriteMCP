# 1. Mục Đích
Sử dụng khi nghiên cứu một chủ đề chuyên sâu, trả lời các câu hỏi phức tạp đòi hỏi thu thập dữ liệu từ nhiều góc nhìn khác nhau.

---

# 2. Cấu Trúc Tổng Hợp

```markdown
# TỔNG HỢP NGHIÊN CỨU: [Chủ Đề Nghiên Cứu]

## 1. Tóm Lược Điều Hành (Executive Summary)
Tóm tắt câu trả lời trực tiếp trong 3-5 câu cốt lõi nhất.

## 2. Ma Trận So Sánh & Đối Chiếu (Comparison Matrix)
| Tiêu chí | Góc nhìn / Nguồn A | Góc nhìn / Nguồn B | Đánh giá Khách quan |
| :--- | :--- | :--- | :--- |
| **Cơ sở lý thuyết** | ... | ... | ... |
| **Ưu điểm nổi bật** | ... | ... | ... |
| **Nhược điểm / Giới hạn** | ... | ... | ... |

## 3. Phân Tích Chuyên Sâu Theo Từng Luận Điểm
- **Luận điểm 1:** [Phân tích + Dẫn chứng thực tế / Nguồn tài liệu]
- **Luận điểm 2:** [Phân tích + Dẫn chứng thực tế / Nguồn tài liệu]

## 4. Kết Luận & Định Hướng Ứng Dụng
Đưa ra kết luận đúc rút và hướng dẫn áp dụng thực tế cho bài toán hiện tại.
```
